## Engineering Principles

```
  I.   Build for the failure case first — the happy path is easy; edge cases define architecture.
 II.   Async everything that doesn't need to block.
III.   A cache you control beats a third-party dependency you don't.
 IV.   Code review is engineering culture, not a bottleneck.
  V.   If it isn't observable, it isn't production-ready.
 VI.   Horizontal scale over vertical — design for it from day one.
VII.   Complexity you introduced is debt you own. Keep it honest.
```
